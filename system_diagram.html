🛡️ Agent-as-Judge Architecture

Multi-Layered Defense System Flow

👤 User Input
User submits a message to the chatbot
↓
🔍 Layer 1: Content Filtering
Embedding-based anomaly detection using semantic similarity

Catches: Semantically unusual inputs, suspicious keywords
Success Rate: 40% of attacks
Tech: Sentence Transformers (all-MiniLM-L6-v2)
Time: ~23ms
↓
🎯 Layer 2: Pattern Detection
Matches against 50+ known attack patterns across 5 categories

Categories: Direct injection, Override, Exfiltration, Context manipulation, Delimiter breaking
Success Rate: 25% of attacks
Tech: Regex patterns + Attack taxonomy
Time: ~5ms
↓
⚖️ Layer 3: Agent-as-Judge ⭐
INNOVATION: Uses Gemini AI to semantically analyze intent and context

Advantages: Understands nuance, detects novel attacks, provides reasoning
Success Rate: 25% of attacks (sophisticated ones)
Tech: Google Gemini 1.5 Flash
Time: ~800ms
↓
🔒 Apply Hierarchical Guardrails
Constructs secured prompt with clear boundaries between system instructions and user data
↓
🤖 Generate Response
Gemini 1.5 Pro generates response with guardrails applied
Tech: Google Gemini 1.5 Pro
Time: ~2200ms
↓
✅ Layer 4: Response Verification
Scans generated output for signs of successful injection

Checks: System prompt leakage, role confusion, excessive disclosure
Success Rate: 10% of attacks (final safety net)
Tech: Pattern analysis + Behavioral checks
Time: ~45ms
↓
✅ Safe Response Delivered
All security checks passed. Response returned to user.

OR (If Attack Detected)

🚫 Attack Blocked
Request blocked at the layer that detected it

User sees: Detailed explanation of why it was blocked, which layer caught it, and the specific reason

System logs: Full attack details for analysis and monitoring
